# Пак для Windows 11: минимальная задержка и максимум FPS

Сделано под: **Ryzen 7 9800X3D + мать ASUS ROG (AM5) + GTX 1080 Ti + Windows 11**.

Всё, что меняет скрипт, записывается в `backup\state.json` и **полностью откатывается** через `2_RESTORE.bat`.
Перед изменениями создаётся точка восстановления Windows.

## Как запустить

1. Скачай папку `win11-gaming-tweaks` (Code → Download ZIP) и распакуй её, например, в `C:\GamingPack`.
2. Запусти **`1_RUN_OPTIMIZE.bat`** и нажми «Да» в запросе прав администратора.
3. Ответь на 6 вопросов (y/n), дождись конца и **перезагрузи ПК**.
4. Сделай ручные шаги ниже (BIOS, драйверы, панель NVIDIA). Они дают больше, чем любой твик Windows.

Откат: **`2_RESTORE.bat`** → перезагрузка. Если что-то пошло совсем не так: `Win+R` → `rstrui` → точка «Before Gaming Low-Latency Pack».

> Не удаляй папку `backup`, пока хочешь иметь возможность откатиться.
> Если скрипт запустить повторно, он не перезапишет исходные значения, так что откат всё равно вернёт систему к состоянию до первого запуска.

## Что делает скрипт

| Блок | Изменения |
|---|---|
| Электропитание | Новый план «Gaming Low Latency» на базе Ultimate Performance: без парковки ядер, без энергосбережения USB и PCIe, CPU min 100%. Отключены Power Throttling, гибернация и быстрый запуск |
| GPU и игры | HAGS (аппаратное планирование GPU) включено, игровой режим включён, Game DVR и фоновая запись выключены, включена оптимизация оконных игр (flip model), MSI-прерывания для видеокарты NVIDIA |
| Планировщик | MMCSS: у игр приоритет GPU и CPU `High`, NetworkThrottling выключен, `Win32PrioritySeparation = 0x26`, глобальное разрешение таймера |
| Ввод | Акселерация мыши выключена (1:1), отключены горячие клавиши залипания и фильтрации клавиш |
| Сеть | Nagle и delayed ACK выключены, у сетевой карты отключено энергосбережение (EEE, Green Ethernet и т. п.), раздача обновлений другим ПК выключена |
| Загрузчик / диск | HPET не форсируется, `disabledynamictick yes`, отключена запись времени последнего доступа NTFS |
| Службы (отключены) | телеметрия (DiagTrack, dmwappushservice), отчёты об ошибках, SysMain, помощник совместимости, карты, геолокация, удалённый реестр, факс, демо-режим, Insider, родительский контроль, Phone, NFC-платежи, Link Tracking |
| Службы (вручную) | обновление Edge, хосты диагностики |
| Фон и телеметрия | телеметрия на минимуме, рекламный ID, история активности, фоновые UWP-приложения, Copilot, Recall, виджеты, веб-поиск в Пуске, советы и автоустановка приложений, Edge в фоне, задачи телеметрии в планировщике |
| Интерфейс | без анимаций, прозрачности и задержки меню и автозагрузки |

### Вопросы при запуске

| # | Вопрос | Когда отвечать `y` |
|---|---|---|
| 1 | Xbox-службы | Не играешь через Game Pass, Xbox app и Microsoft Store (игры из Steam, Epic и Battle.net работают без них) |
| 2 | Печать | Нет принтера |
| 3 | Bluetooth | Нет BT-наушников, геймпада и других BT-устройств |
| 4 | Windows Search | Не ищешь файлы через Пуск (приложения в Пуске будут находиться) |
| 5 | **VBS / Memory Integrity / Hyper-V** | Даёт самый заметный прирост FPS (5–10% и стабильнее 1% low). **Не** включай, если нужны WSL2, Hyper-V, Android-эмулятор на Hyper-V или античит, который требует VBS (например, FACEIT). Vanguard (Valorant) требует TPM и Secure Boot, но не VBS |
| 6 | Службы ASUS Armoury Crate | Если RGB и вентиляторы настроены в BIOS и Armoury Crate не нужен. LightingService заметно грузит CPU |

Что скрипт **не** трогает специально: Windows Defender, Windows Update, брандмауэр, звук и драйверы. Это ломает систему или безопасность, а FPS почти не добавляет.

## Ручные шаги (они важнее всего)

### 1. BIOS (ASUS ROG, AM5)

1. **Обнови BIOS** до последней версии с сайта ASUS (новые AGESA дают лучший буст и стабильную память).
2. **EXPO**: `Ai Tweaker → Ai Overclock Tuner → EXPO I`. Без него память работает на 4800 вместо 6000+. Это самый большой прирост из всех пунктов.
   Оптимум для 9800X3D: DDR5-6000 CL30, `FCLK 2000`, `UCLK = MEMCLK` (1:1).
3. **PBO** (9800X3D поддерживает разгон):
   `Advanced → AMD Overclocking → Precision Boost Overdrive → Advanced`
   - `PBO Limits: Motherboard`
   - `Max CPU Boost Clock Override: +200 MHz`
   - `Curve Optimizer: All Cores → Negative → 15` (потом можно пробовать 20–30)
   - Проверь стабильность: OCCT, CoreCycler или Cinebench R23 (30 минут). Если ПК зависает или выдаёт WHEA-ошибки, уменьши значение Curve Optimizer.
4. **Global C-State Control** оставь `Auto`. На Ryzen его отключение **снижает** буст.
5. **SVM Mode** выключи, если не пользуешься виртуалками, WSL2 и VBS.
6. `Tool → ASUS Armoury Crate → Download & Install ARMOURY CRATE app → Disabled`, если Armoury Crate не нужен. Тогда Windows не будет ставить его снова.
7. Кривые вентиляторов настрой в `Monitor → Q-Fan Configuration`.
8. Resizable BAR ничего не даст: GTX 1080 Ti его не поддерживает.

### 2. Драйверы

1. **AMD Chipset Driver**: скачай последний с amd.com (Drivers → Chipsets → AM5 → твой чипсет). Он важен для правильного управления питанием Ryzen.
2. **Драйвер NVIDIA**, чистая установка:
   - Скачай драйвер для GTX 1080 Ti с nvidia.com. Серия GTX 10 после ветки 580 получает только обновления безопасности, так что ставь последний доступный для твоей карты драйвер.
   - Загрузись в безопасный режим, удали старый драйвер через **DDU** (Display Driver Uninstaller), перезагрузись.
   - Установи драйвер через **NVCleanstall**: только Display Driver (и HD Audio, если звук идёт через HDMI/DP монитора). Включи `Disable Installer Telemetry & Advertising`.
3. Драйвер сетевой карты (Intel I226-V или Realtek 2.5G) скачай с сайта ASUS под свою материнку.

### 3. Панель управления NVIDIA

`Управление параметрами 3D → Глобальные параметры`:

| Параметр | Значение |
|---|---|
| Режим низкой задержки (Low Latency Mode) | **Ultra**. В играх с NVIDIA Reflex включай в игре Reflex **On + Boost** |
| Режим управления электропитанием | **Предпочтителен режим максимальной производительности** |
| Фильтрация текстур: качество | **Высокая производительность** |
| Размер кэша шейдеров | **10 ГБ** или **Не ограничено** |
| Потоковая оптимизация | Авто |
| Вертикальный синхроимпульс | **Выкл**. С G-Sync/FreeSync-монитором: **Вкл** + лимит FPS ниже |
| Макс. частота кадров | С G-Sync: частота монитора −3 (например, 141 для 144 Гц, 237 для 240 Гц). Без G-Sync: выкл |

А ещё:
- `Изменение разрешения`: максимальная частота обновления монитора, `Выходной динамический диапазон: Полный`.
- `Регулировка размера и положения рабочего стола`: `Без масштабирования`, масштабирование выполняет **дисплей**.
- С G-Sync-монитором: `Настройка G-SYNC → Включить для полноэкранного и оконного режимов`.

### 4. Windows (руками)

- `Параметры → Дисплей → Расширенные параметры дисплея`: выбери максимальную частоту (144/165/240 Гц). Часто она стоит на 60 Гц.
- `Диспетчер задач → Автозагрузка`: отключи всё лишнее (Discord, Steam, лаунчеры и т. п.).
- Мышь: частота опроса 1000 Гц или выше в ПО мыши.
- Defender: `Защита от вирусов → Исключения`: добавь папки библиотек Steam и Epic. Меньше лагов при компиляции шейдеров и обновлениях игр.
- Игры держи на NVMe SSD.

### 5. В играх

- Полноэкранный режим (Fullscreen), а не «окно без рамки», если игра это позволяет.
- **NVIDIA Reflex: On + Boost** везде, где он есть (CS2, Valorant, Fortnite, Apex, CoD, Overwatch 2 и др.).
- Ограничь FPS встроенным лимитом игры: он даёт меньшую задержку, чем внешние лимитеры.
- С 9800X3D узкое место почти всегда 1080 Ti. Если загрузка GPU 97–99%, снижай графику или разрешение рендера: задержка упадёт сильнее всего.

## Проверка результата

- **LatencyMon**: запусти на 5–10 минут; в идеале «Your system appears to be suitable for handling real-time audio».
- `msinfo32` → «Безопасность на основе виртуализации: Не включено» (если отключал VBS).
- Сравни FPS и 1% low в одной и той же сцене до и после (CapFrameX или встроенный бенчмарк игры).
