# Брейнроты — модели для UEFN

Классические мем-брейнроты, гладкие мультяшные модели. Пилот: 3 из 40. Статичные меши для подставок в тайкуне.

| Персонаж | Треугольники | Размер (Ш×Г×В) | Превью |
|---|---|---|---|
| 67 (Six Seven) | 15 000 | 192×36×140 см | [preview](SixSeven_67/preview.png) |
| Тралалеро Тралала | 15 000 | 160×63×139 см | [preview](Tralalero_Tralala/preview.png) |
| Тунг Тунг Тунг Сахур | 15 000 | 123×46×175 см | [preview](Tung_Tung_Tung_Sahur/preview.png) |

Каждая папка: `SM_<Имя>.fbx` (меш), `T_<Имя>_BaseColor.png` (текстура 2048², все цвета запечены),
`preview.png`, `info.json`. Один материал на модель. Пивот — центр основания на полу, лицо смотрит вперёд.

## Импорт в UEFN
1. Content Browser → **Import** → FBX и PNG. В окне FBX: **Static Mesh**, `Skeletal Mesh` выключен,
   `Combine Meshes` включён.
2. Если материал не подключился сам: `Texture Sample` с `T_..._BaseColor` → **Base Color**, Roughness ≈ 0.5.
3. Откройте меш → **LOD Settings**: `Number of LODs = 3` → Apply — когда в кадре много брейнротов.
4. Коллизия: в редакторе меша `Collision → Add Box/Capsule Simplified Collision`.
5. Если на карте одновременно видно больше 15–20 брейнротов — у текстур `Max Texture Size = 1024`.
6. Покачивание и вращение на подставке — через Verse.

## Как устроен генератор
Персонаж рисуется объёмными формами (капсулы, эллипсоиды, штрихи-«шрифт», треугольники) на мелкой сетке.
Затем строится гладкая поверхность, упрощается до 15 000 треугольников, а цвета с детальной копии
запекаются в одну текстуру.
```
pip install bpy==4.2.0 pillow numpy scipy scikit-image   # Python 3.11
python tools/build.py                                   # все персонажи
python tools/build.py SixSeven_67
```
- `tools/voxel_chars.py` — персонажи. Новый брейнрот = новая функция + строка в `VOX_CHARACTERS`.
  `K = 1` в начале файла — пиксельный стиль вместо гладкого.
- `tools/voxel.py` — рисование формами, гладкая поверхность, запекание цветов.
- `tools/kit.py` — экспорт FBX и превью-рендер.
